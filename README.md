# ByAzen

**ByAzen** — клиент для Minecraft **1.21.11** (Fabric). Полностью переименованная (ребренд) версия проекта
Kimiko: все пакеты, классы, ресурсы, мод-ид и строки интерфейса теперь носят имя **ByAzen**.

## Что было переименовано

* `rtx.kimiko` → `rtx.byazen` — пакеты, классы и все `import` в ~920 файлах
* `Kimiko.java` → `ByAzen.java`, `KimikoMixinPlugin` → `ByAzenMixinPlugin`
* `kimiko.mixins.json` → `byazen.mixins.json`, `kimiko.accesswidener` → `byazen.accesswidener`
* `assets/kimiko/**` → `assets/byazen/**` — шейдеры, модели, текстуры, шрифты, gif, звуки
* `LICENSE_kimiko` → `LICENSE_byazen`, `META-INF/services/rtx.kimiko.*` → `rtx.byazen.*`
* namespace `kimiko:` → `byazen:` (шейдеры `#moj_import <byazen:common.glsl>`, текстуры, gif, буферы, потоки)
* `fabric.mod.json`, `gradle.properties`, `settings.gradle` — id, группа, имя архива (`ByAzen-1.0.0.jar`)

Не тронута одна внешняя ссылка оригинального проекта (чужой рабочий адрес, переименование сделало бы
кнопку нерабочей):

* `src/main/java/rtx/byazen/utils/discord/rpc/DiscordRPCManager.java` — `https://t.me/kimikodlc`

Мёртвый адрес аватарки `https://kimiko_tech/api/account/avatar/` из `ProfileIdentity` удалён ещё в 1.1.0.

Исходный архив `Kimiko_Fix_Src.zip` удалён из рабочей ветки — его содержимое распаковано и переименовано прямо
в репозитории. Сам архив по-прежнему доступен в истории git (`git show 4c5fd8d:Kimiko_Fix_Src.zip`).

## Сборка

### GitHub Actions (использовалась для этого jar)

Workflow [`.github/workflows/build.yml`](.github/workflows/build.yml) собирает мод на раннере GitHub (там
доступны `maven.fabricmc.net`, `libraries.minecraft.net`, Maven Central) и публикует готовый jar обратно
в корень ветки. Запуск: push в `arena/**` / `main` или вручную (Actions → *Build ByAzen* → Run workflow).
Jar пишется детерминированно, поэтому повторная сборка без изменений в коде не создаёт лишних коммитов.

### Что ещё проверяет CI

Перед релизом workflow делает две проверки, чтобы клиент не «упал» у игрока:

* **Audio smoke test** — скачивает тестовый MP3 и декодирует его тем же кодом, что и плеер в игре
  (JLayer, поток без записи на диск): в логе видно число фреймов, частоту, каналы, длительность, peak и RMS.
* **Verify built jar** (`tools/verify_jar.py`) — сверяет версию в `fabric.mod.json` с `gradle.properties`,
  сверяет объявленный список вложенных jar с реально лежащими внутри и проверяет наличие ключевых классов.

### Локально (Windows / Linux)

```bash
gradlew.bat build        # Windows (JDK 21 в PATH)
./gradlew build          # Linux / macOS
```

Готовый файл: `build/libs/ByAzen-1.2.1.jar`.

> В песочнице, где делался ребренд, наружу открыт только GitHub/PyPI, поэтому Maven-репозитории недоступны —
> сборка выполнялась на GitHub Actions, а не локально.

## Установка

1. Установите Fabric Loader 0.19.3+ для Minecraft 1.21.11.
2. Положите Fabric API (`fabric-api-0.141.6+1.21.11.jar`) в `.minecraft/mods`.
3. Положите `ByAzen-1.5.2.jar` в `.minecraft/mods`.
4. Запустите игру.

Отдельно ставить `Pulse-Cosmetics` и `KillEffect` **не нужно** — оба мода вложены внутрь `ByAzen-1.5.2.jar`
(jar-in-jar) и загружаются вместе с клиентом.

## Что нового в 1.5.2 — визуалы мира, часть III

* **Свои частицы (№51).** Мир наполняется мелкой жизнью: в снежных биомах кружатся снежинки, в лесу
  летят листья, у лавы поднимаются искры, на песке висит пыль, над водой всплывают пузыри. Стиль
  подбирается по блокам вокруг, у каждого своя физика — снег падает, искры взлетают, пыль висит.
* **Bloom (№53).** Лава, порталы, кристаллы, руды, факелы и огонь получают мягкое радиальное
  свечение с плавным «дыханием» и необязательными искрами. Свечение честно уходит за блоки и не
  светит сквозь стены.
* **Трейлы 2.0 (№58).** За элитрами вьётся спиральный завиток, за стрелами и трезубцами тянется
  шлейф, за снарядами и предметами — мягкая пыль. Частицы считаются по пройденному пути, поэтому
  след не рассыпается на медленных скоростях.
* **Подсветка блоков (№62).** Руды, контейнеры, рабочие станции, порталы и свои блоки (списком)
  обводятся градиентным контуром с переливом или пульсом, плюс мягкая заливка внутри.

## Что нового в 1.5.1 — визуалы мира, часть II

* **Glow ESP по категориям (№61).** Прежний режим подсветки был заглушкой — теперь он реально
  рисует мягкий ореол, лёгкую заливку и аккуратный контур вокруг цели. Категории: игроки, мобы,
  выпавшие предметы и контейнеры (сундуки, бочки, шалкеры), у каждой — свой цвет. Скан контейнеров
  идёт волной по одному слою за тик, поэтому даже радиус 40 блоков не роняет FPS.
* **Мягкие тени (№54).** Под игроками, мобами и предметами появляется контактная тень, которая
  плотнее у земли и исчезает на высоте: несколько плоских слоёв дают мягкий край без пикселей.
* **Анимации смерти (№57).** Когда моб или игрок умирает, на его месте разлетаются сглаженные
  частицы выбранной формы плюс короткая вспышка; настраиваются количество, разлёт, время жизни,
  гравитация и цвета.
* **Осколки при разрушении блока (№64).** Блок разлетается осколками **своего цвета** (трава —
  зелёными, песок — тёплыми, руды — с оттенком акцента), с мягкой пылью, вращением и прозрачностью.

## Что нового в 1.5.0 — визуалы мира, часть I

* **Мини-карта (№71).** Виджет с рельефом вокруг вас: трава, песок, камень, вода, руды и постройки
  читаются по цвету, склоны подсвечиваются — карта выглядит объёмно. Отметки игроков, мобов и
  путевых точек, стрелка взгляда, компас, координаты и выбор: «север сверху» или «по взгляду».
  Карта считается порциями по несколько строк за тик, поэтому большой радиус не роняет FPS.
* **Путевые точки (№72).** `waypoint add Дом`, `waypoint list`, `waypoint go Дом`, `waypoint remove`.
  Точка подсвечивается столбом света и меткой на земле, видна на мини-карте, а в HUD есть список
  ближайших точек с расстоянием. Сохранение с клавиши, свои цвета, переход по команде.
* **Яркость и ночное зрение (№73).** Ползунок яркости до 12× с плавным переходом: видно ночью и в
  шахтах, при этом ванильная настройка гаммы не портится. Есть «только ночью», «уважать зелье» и
  «не в аду и краю».
* **Пост-эффекты урона (№75).** Вместо резкой красной рамки — мягкий градиент по краям экрана,
  пульс при низком здоровье и деликатная дуга с направления, откуда прилетело.
* **Кино-режим (№60).** Виньетка, полосы кадра, лёгкое зерно плёнки и плавные переходы;
  включается клавишей, как «камера в руках».

## Что нового в 1.4.1 — остаток волны 5

* **Масштаб интерфейса (№34).** Свой масштаб меню клиента от 0.5 до 2.0 — удобно на 4K и ultrawide,
  когда ванильные «маленький/обычный/большой» не подходят. Масштабируются ClickGui и все экраны
  ByAzen; на время расстановки HUD масштаб можно автоматически выключать, чтобы мышь и виджеты совпадали.
* **Плашка под музыку (№26).** Виджет «сейчас играет» с анимированным градиентом прямо из красок
  обложки трека, миниатюрой обложки, живым эквалайзером, бегущей строкой названия и полосой прогресса.
* **Группы виджетов (№31).** Виджеты, стоящие в одной колонке (или строке), получают одну общую
  подложку с настройкой допуска, отступов, скругления, плотности, рамки и разделителей.
* **Виджет «следующий ивент» (№37).** Данные запрашиваются у сервера через LiteApi: имя ивента,
  подробности и обратный отсчёт. Пока сервер молчит — виджет можно прятать.
* **Свои шрифты (№49) и читаемость (№195).** TTF/OTF из `.minecraft/byazen/fonts` подключаются к
  интерфейсу, но только если проходят проверку сглаженности — пиксельные шрифты отклоняются.
  Плюс общий масштаб текста клиента. Команды: `fonts`, `fonts reload`, `fonts use <название>`.
* **Полные темы (№50).** Тёмная, светлая и неоновая темы: подложки, цвет надписей и ванильные экраны
  (инвентарь, сундук, меню) подстраиваются под выбранную тему.
* **Переключатель RU/EN (№44).** Язык интерфейса клиента переключается в модуле `Language`;
  экраны и подсказки клиента (галерея, плашки, уведомления) сразу меняют язык.

## Что нового в 1.4.0

* **Галерея скриншотов (№45).** Новый модуль `Screenshots`: сетка превью прямо в игре, полноэкранный
  просмотр, листание стрелками, удаление (с подтверждением), копирование пути (`C`) и открытие папки
  (`O`). Превью грузятся плавно (без пикселизации) и декодируются вне кадра, так что игра не дёргается.
  Клавишу открытия галереи можно назначить, а о новом снимке клиент сообщает всплывашкой.
* **Водяной знак 2.0 (№46).** Три вида плашки («Плашка», «Минимал», «Только логотип»), свой цвет
  с градиентом, готовые позиции (шесть углов и центров) плюс свободное перетаскивание, а также
  новые данные: FPS, пинг и TPS. На стриме ник автоматически подменяется.
* **Стрим-режим 2.0 (№47).** Кроме ников и координат теперь скрываются IP-адреса и суммы,
  появилось «замазывание» чата: строки чата на экране закрываются блоками, а назначенная клавиша
  временно показывает их вам. Водяной знак и тосты тоже уважают стрим-режим.
* **Прицел 3.0 (№48).** Анимация удара: при попадании прицел вспыхивает, расходится кольцом и
  оставляет четыре отметки-штриха по диагонали. Отдельные прицелы для ситуаций — лук, арбалет и
  трезубец («Точка»), кровать и якорь взрыва («Кольцо» или «Скрыть»), чтобы не мешать в PvP.

## Что нового в 1.3.2

* **Поиск по настройкам (Ctrl+F).** В ClickGui открывается палитра: ищет по названиям модулей,
  названиям настроек и их описаниям. Выбор результата открывает окно настроек нужного модуля и

* **Избранные модули.** У каждой карточки появилась звёздочка: избранные модули поднимаются наверх
  списка в своей категории, а поиск по настройкам показывает их первыми.
* **Пресеты настроек модуля.** В шапке окна настроек три кнопки: сброс к значениям по умолчанию,
  «копировать пресет» и «вставить пресет». Пресет — короткий код `BZ1.…`, его можно отправить другу.
* **Подсказки.** При наведении на настройку показывается её описание; у кнопок шапки — свои подсказки.
* **Журнал изменений.** Клиент запоминает, что и когда вы меняли: `history`, `history <модуль>`,
  `history clear` (хранит 200 последних записей).
* **«Где это найти».** Команда `find <текст>` открывает ClickGui на нужной категории и подсвечивает
  модуль — полезно, когда нужно быстро выключить какую-то штуку, но лень искать.
* **Алармы таймеров.** Новый модуль `Timer Alarms`: предупреждает об окончании зелий (порог в секундах,
  только полезные эффекты) звуком, сообщением и всплывашкой в HUD.

## Что нового в 1.3.0 — музыкальный плеер

Встроенный плеер: игрокам **не нужно ничего скачивать** — музыка идёт потоком прямо в игру
(интернет-радио и онлайн-каталог треков), декодируется на лету и играет через звук Minecraft.

* **Модуль `Music Player`** (категория Display, включён по умолчанию).
  Клавиша **M** открывает окно плеера, а в HUD живёт компактный виджет с обложкой, названием,
  живым спектром, кнопками ⏮ ⏯ ⏭ и полосой прогресса. Виджет перетаскивается в редакторе интерфейса,
  громкость меняется колесом мыши прямо на самом виджете.
* **Библиотека из 25 станций** уже в клиенте: SomaFM (Groove Salad, Drone Zone, Deep Space One,
  Secret Agent, Metal Detector, DEF CON Radio и другие) и Nightride FM (синтвейв, чиллвейв, дарксинт).
  Станции не требуют регистрации и работают в любом мире — звук не зависит от позиции в игре.
* **Онлайн-каталог (Audius) и радио-директория (radio-browser).** Вкладка «Поиск» ищет треки
  по названию, артисту и жанру, показывает популярное при открытии и умеет играть с обложками.
  Если у станции сменился адрес потока, плеер сам спросит каталог и переподключится.
* **Свои ссылки.** Вкладка «Свои ссылки» принимает любую прямую ссылку на поток (MP3/OGG-стрим, WAV).
* **Избранное** сохраняется в конфиг ByAzen (`music_library.byazen`) вместе с историей прослушивания.
* Отрисовка полностью векторная: скруглённые панели, градиентные акценты, размытие фона,
  плавные анимации строк и сглаженный шрифт Montserrat — никакой «пиксельной» графики.

## Что нового в 1.2.1

* **Починены кнопки в настройках модулей.** Раньше нажатие на строку-кнопку (`ButtonSetting`) не срабатывало

## Что нового в 1.2.0

* **Встроены моды Pulse Cosmetics и Kill Effect** — как вложенные jar-ы (`META-INF/jars/*.jar`), с записью
  в `fabric.mod.json`; соответствие «объявлено ↔ лежит в jar» проверяется при сборке.
* **Новые модули** `Pulse Cosmetics` и `Kill Effect 3D` (Visuals) с кнопками, мультивыбором и селектом эффектов.
* **Кнопки в настройках теперь видны.** Раньше строки `ButtonSetting` рисовались пустыми (кликабельная, но
  невидимая строка). Теперь у них аккуратная пилюля-кнопка с подписью и название настройки — как у остальных

  клиент просто отключает мост и продолжает работать.

## Модули 1.2.0: Pulse Cosmetics и Kill Effect 3D

Оба мода встроены в клиент как вложенные jar-ы и управляются из списка модулей ByAzen (категория **Visuals**).

### Pulse Cosmetics

Косметика Pulse: крылья, плащи, головные уборы, одежда на теле, питомцы и граффити.

| Настройка | Что делает |
|---|---|
| **Меню косметики** → «Открыть» | Открывает полное меню Pulse Cosmetics (превью, вкладки, выбор косметики) |
| **Чужая косметика** | Мультивыбор категорий: показывать ли косметику других игроков |
| **Питомец в 1-м лице** | Показывать собственного питомца от первого лица |
| **Очиститель граффити** → «Включить» | Режим удаления граффити: навестись на рисунок и нажать ПКМ |

Модуль синхронизирован с меню самого мода: переключатели в нём и в ClickGui всегда показывают одно и то же.
Пока модуль **выключен**, чужая косметика скрыта, а питомец не рисуется от первого лица.

### Kill Effect 3D

3D-эффекты убийства из мода Kill Effect (модели Blockbench с анимациями и текстурами).

| Настройка | Что делает |
|---|---|
| **Эффект** | Выбор эффекта прямо из ClickGui (39 эффектов, названия как в моде) |
| **Меню эффектов** → «Открыть» | Полное меню Kill Effect с превью всех эффектов |

Модуль является главным выключателем: пока он **выключен**, ни один 3D-эффект не появляется (спавн блокируется

## Правила проекта

1. **Красивый рендер, никакой пикселизации.** Пиксельные/битмап-шрифты в проекте запрещены:
   только гладкие MSDF-шрифты (Montserrat, SF Pro) и сглаженная векторная графика. Всё, что добавляется в ByAzen, рисуется сглаженно:
   шейдеры/SDF, плавные скругления, градиенты, MSAA/суперсэмплинг, интерполяция координат и альфы
   (`float`, а не округлённые пиксели), мип-мапы и линейная фильтрация. Никакого pixel-art, `NEAREST`-фильтра,
   шага по целым пикселям и нарочито «пиксельных» текстур/иконок.
2. Все новые файлы, пакеты и ресурсы — в пространстве имён `byazen` (`rtx.byazen.*`, `assets/byazen/**`).
3. Никаких упоминаний старого имени в коде, ресурсах и UI.
