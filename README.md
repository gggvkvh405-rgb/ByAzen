# ByAzen

**ByAzen** — клиент для Minecraft **1.21.11** (Fabric). Полностью переименованная (ребренд) версия проекта
Kimiko: все пакеты, классы, ресурсы, мод-ид и строки интерфейса теперь носят имя **ByAzen**.

## Что было переименовано

* `rtx.kimiko` → `rtx.byazen` — пакеты, классы и все `import` в ~920 файлах
* `Kimiko.java` → `ByAzen.java`, `KimikoMixinPlugin` → `ByAzenMixinPlugin`
* `kimiko.mixins.json` → `byazen.mixins.json`, `kimiko.accesswidener` → `byazen.accesswidener`
* `assets/kimiko/**` → `assets/byazen/**` — шейдеры, модели, текстуры, шрифты, gif, звуки
* `LICENSE_kimiko` → `LICENSE_byazen`, `META-INF/services/rtx.kimiko.*` → `rtx.byazen.*`
* namespace `kimiko:` → `byazen:` (шейдеры `#moj_import <byazen:common.glsl>`, текстуры, gif, буферы, потоки)
* `fabric.mod.json`, `gradle.properties`, `settings.gradle` — id, группа, имя архива (`ByAzen-1.0.0.jar`)

Не тронута одна внешняя ссылка оригинального проекта (чужой рабочий адрес, переименование сделало бы
кнопку нерабочей):

Исходный архив `Kimiko_Fix_Src.zip` удалён из рабочей ветки — его содержимое распаковано и переименовано прямо
в репозитории. Сам архив по-прежнему доступен в истории git (`git show 4c5fd8d:Kimiko_Fix_Src.zip`).

## Сборка

### GitHub Actions (использовалась для этого jar)

Workflow [`.github/workflows/build.yml`](.github/workflows/build.yml) собирает мод на раннере GitHub (там
доступны `maven.fabricmc.net`, `libraries.minecraft.net`, Maven Central) и публикует готовый jar обратно
в корень ветки. Запуск: push в `arena/**` / `main` или вручную (Actions → *Build ByAzen* → Run workflow).
Jar пишется детерминированно, поэтому повторная сборка без изменений в коде не создаёт лишних коммитов.

### Что ещё проверяет CI

Перед релизом workflow делает две проверки, чтобы клиент не «упал» у игрока:

* **Audio smoke test** — скачивает тестовый MP3 и декодирует его тем же кодом, что и плеер в игре
  (JLayer, поток без записи на диск): в логе видно число фреймов, частоту, каналы, длительность, peak и RMS.
* **Verify built jar** (`tools/verify_jar.py`) — сверяет версию в `fabric.mod.json` с `gradle.properties`,
  сверяет объявленный список вложенных jar с реально лежащими внутри и проверяет наличие ключевых классов.

### Локально (Windows / Linux)

```bash
gradlew.bat build        # Windows (JDK 21 в PATH)
./gradlew build          # Linux / macOS
```

Готовый файл: `build/libs/ByAzen-1.2.1.jar`.

> В песочнице, где делался ребренд, наружу открыт только GitHub/PyPI, поэтому Maven-репозитории недоступны —
> сборка выполнялась на GitHub Actions, а не локально.

## Установка

1. Установите Fabric Loader 0.19.3+ для Minecraft 1.21.11.
2. Положите Fabric API (`fabric-api-0.141.6+1.21.11.jar`) в `.minecraft/mods`.
3. Положите `ByAzen-1.7.0.jar` в `.minecraft/mods`.
4. Запустите игру.

Отдельно ставить `Pulse-Cosmetics` и `KillEffect` **не нужно** — оба мода вложены внутрь `ByAzen-1.7.0.jar`
(jar-in-jar) и загружаются вместе с клиентом.

## Что нового в 1.7.0 — конфиги, темы и производительность (волна 9, часть 1)

* **Облачные конфиги с откатом (№151).** Клиент сам оставляет версии настроек — при выходе из мира,
  по таймеру и вручную. Экран «Версии настроек» 520×300 показывает дату, размер и короткий отпечаток;
  любую версию можно вернуть одним кликом (перед откатом клиент сохраняет текущее состояние как
  «before-rollback»), удалить или выгрузить коротким кодом `BZCFG1:…` и перенести на другой ПК.
  История ограничена 40 версиями, так что папка не растёт бесконечно.
* **Профили под сервер (№152).** Модуль `Server Profiles` запоминает включённые модули и тему для
  каждого адреса и расставляет их при входе: на PvP-сервере — боевое окружение, на строительном —
  косметика и музыка. Одиночная игра не трогается, клавиши ведёт отдельный профиль (№97).
* **Импорт конфигов других клиентов (№153).** Клиент ищет рядом с игрой папки Lunar, Badlion, Feather,
  LabyMod, Meteor, Wurst и любые папки со словом «client», показывает по каждому, сколько нашлось
  клавиш и ползунков, и переносит их: клавиши раскладываются по нашим модулям, FOV и дальность
  прорисовки применяются к настройкам игры. Непонятный файл просто пропускается.
* **Тема коротким кодом (№154).** Код `BZTHM1:…` уносит цвета, второй цвет, радугу и стиль градиента:
  «скопировать код темы» → отправить другу → «применить код из буфера». Код короткий и помещается в чат.
* **Редактор темы (№155).** Экран 620×340: поле подбора цвета с пипеткой, палитра светлых и тёмных
  оттенков темы, оттенки из обложки играющего трека и живой предпросмотр карточки модуля. Кнопки
  «радуга», «сбросить цвет», Tab меняет основной и второй цвет.
* **Анимированные фоны ClickGui (№156).** По меню медленно плывёт градиент темы, поднимаются мягкие
  частицы, а если играет музыка — низ панели подкрашивается цветом обложки трека. Всё регулируется в
  модуле `ClickGui Backdrops`: градиент, частицы, оттенок обложки и общая яркость. Фон не мешает
  читать список модулей: карточки рисуются поверх.
* **Читаемый JSON и валидатор (№157).** Кнопка «Записать читаемый JSON» сохраняет настройки с
  отступами в `config-versions/../readable/settings.json`, а проверка объясняет простыми словами, что
  не так: модуля больше нет, настройка называется иначе или значение не подходит по типу. Есть и в
  чате: `.config check` и `.config readable`.
* **Точечный сброс (№158).** В шапке окна настроек появилась четвёртая кнопка — сброс модуля целиком:
  настройки, клавиша, режим нажатия и включённость возвращаются как у модуля из коробки. Из чата то же
  самое: `.config reset <модуль>` и `.config reset <модуль> <настройка>` для одной настройки.

## Что нового в 1.6.1 — косметика, социальное, клиент (волна 8)

* **Каталог косметики (№121, №122, №124).** 41 предмет: базовые и три сезонных набора — «Зима»,
  «Неон», «Космос» по 10 предметов. Каталог 566×306 с живым 3D-превью: модель можно крутить мышью,
  приближать колесом; снятие и надевание в один клик, избранное, фильтры по наборам, выдача кодом
  `BZGS1:` или JSON (в том числе от LiteApi). Сдвиги, размер, частицы и видимость на других — в
  настройках модуля `Cosmetics 3D`.
* **Плащи с физикой (№123).** Модуль `Animated Capes`: плавный или блочный край, четыре типа физики,
  ветер, вес ткани, длина и отставание — и три пресета под наборы. Переливающийся плащ ByAzen
  включается и выключается на ходу, обычный вид не ломается.
* **Эмоции 2.0 (№125).** Позы действительно проигрываются: нарастание и затухание, чтобы переход не
  рвался; чужие эмоции считаются от времени старта, поэтому у всех на экране выглядят одинаково.
  Включён режим «только тиммейты» — чужие эмоции от незнакомцев не показываются. Эмоцию можно
  вызвать из чата: «!танец», «!помахать», «!аплодисменты».
* **Звуки косметики (№126).** 11 своих .ogg 44.1 кГц: надевание, снятие, избранное, получение набора,
  три звука наборов и четыре звука питомца. Громкость каждого файла делится на измеренный пик,
  поэтому ни один звук не «стреляет» громче остальных.
* **Питомцы (№127, №128).** Модуль `Pet Style`: цвет, акцент, размер, имя, аксессуар (бант, шляпа,
  шарф, корона, очки), аура и кольцо настроения; размер модели меняется сразу. Экран «Игры с
  питомцем»: покормить, погладить, игрушка, «ко мне» — с карточкой настроения и переименованием.
  Опыт растёт в бою (+2 за удар, уровни), а на смерти питомец расстраивается.
* **Kill-эффекты (№129).** Случайный эффект из отмеченного списка (39 эффектов), интервал смены и
  звук ByAzen в момент появления эффекта с регулировкой громкости.
* **Следы под ногами (№130).** Светящиеся отпечатки: чередование левая-правая, разворот по ходу,
  размер, шаг, время жизни, свечение, следы других игроков и питомца, цвета наборов.
* **Обложки профиля (№131).** Четыре живые GIF-обложки — «Неон», «Зима», «Космос», «Карамель» —
  с настоящей анимацией: экран выбора 520×268, карточка игрока с уровнем питомца и коллекцией,
  сезонный режим (зимой — «Зима»).

## Что нового в 1.6.0 — утилиты и удобство (волна 7)

* **Профили клавиш под сервер (№97).** У каждого адреса свой набор биндов: клиент сам расставляет
  сохранённый профиль при входе, запоминает клавиши на новом сервере и держит общий профиль для
  остальных. Одиночная игра и локальная сеть не трогаются.
* **Проверка серверов (№99).** Окно избранных адресов: пинг, игроки, версия и описание обновляются
  сами, вход — в один клик. При подключении клиент коротко сообщает состояние сервера в чат.
* **Менеджер модов (№100).** Список модов с поиском, все клавиши вместе с модом-владельцем (сразу
  видно, «какой мод добавил эту кнопку»), поиск по содержимому jar-файлов и предупреждение о
  совпадающих клавишах при запуске.
* **Обмен конфигурацией (№101).** Вся конфигурация клиента собирается в один файл `.bycfg`, профиль
  модуля показывается QR-кодом для телефона, импорт применяется сразу и делает резервную копию.
* **Автобэкапы конфигов (№102).** Копия настроек при запуске, по таймеру, вручную и перед сменой
  профиля: список копий, восстановление одной кнопкой и обрезка старых, чтобы папка не росла.
* **Оффлайн-справочник (№106).** Команды клиента с текущим префиксом, назначенные клавиши, калькулятор
  координат Нижнего и Верхнего мира, зелья, зачарования, тайминги и мелочи выживания — с поиском и
  мгновенным открытием прямо в игре.
* **Аннотатор снимков (№109).** Разметка снимка в клиенте: стрелка, рамка, круг, линия и подпись,
  палитра, три толщины, отмена шагов и сохранение в PNG рядом с исходником. Кнопка «Отметить» в
  галерее и клавиша `R`.
* **Авто-снимки (№110).** Кадр сохраняется сам в важный момент: смерть, достижение, закат, рассвет и
  первое посещение биома. Между снимками — настраиваемая пауза, поэтому папка не превращается в свалку.
* **Ревизор ресурспаков (№115).** Проверка наборов: версия упаковки, число файлов и размер, крупные
  текстуры, ошибки упаковки и перекрытия между наборами. Короткий итог при входе и полный отчёт по кнопке.
* **Пресеты графики (№116).** «PvP 240 fps», «Баланс», «Кино 60 fps» и «Стрим» одним нажатием: вместе с
  настройками игры переключаются тяжёлые модули клиента, а кнопка «Вернуть как было» откатывает всё.
* **Мониторинг FPS (№117, №118).** График FPS с мягкой заливкой, средний FPS и «1% low», предупреждение
  о просадках — появился в 1.3.2 и живёт рядом с новыми утилитами.
* **Авто-переподключение (№119).** Возврат на сервер после обрыва: обратный отсчёт в виджете, место в
  очереди с экрана отключения, растущая пауза между попытками. После бана, кика или запроса пароля
  клиент сам не входит — чтобы не выглядеть навязчиво.

## Что нового в 1.5.4 — косметика и инвентарь

* **Custom Swords 2.0 (№65).** Редактор моделей оружия: большое превью под мягким свечением,
  каталог всех моделей с поиском по названию и выбором в одно нажатие. Плюс виджет HUD с иконкой
  выбранного оружия и подписью модели — он таскается как остальные элементы интерфейса.
* **Крылья с физикой ткани (№66).** Крыло — настоящая ткань: сетка точек на пружинах считается
  методом Верле, поэтому крылья отстают при разгоне, колышутся от ветра, расправляются в падении и
  складываются, когда вы стоите. Три формы (Ангел, Дракон, Мотылёк), градиент к кончикам перьев,
  свечение акцента и искры при быстром полёте.
* **Питомцы 2.0 (№67).** Питомец переживает за хозяина: радуется ударам, визжит от тотема, грустит
  при смерти и повторяет прыжки. Эмоции летят над головой мягкими светящимися частицами, анимация
  питомца встряхивается, а звуки стали живыми. Есть и просто игры при простое.
* **Граффити 2.0 (№68).** Встроенный редактор: векторные слои «Фон» и «Штрихи», кисть с мягкими
  линиями, ластик, палитра, отмена шагов. Сохранение собирает слои в PNG с антиалиасингом, а
  рисунок вешается на грань блока под прицелом — со свечением, поворотом и плавным появлением.
* **Кастомный инвентарь (№69).** Кнопка «Сортировать» раскладывает вещи по категориям, по имени или
  по количеству (с хотбаром). Фильтр подсвечивает нужную группу и мягко затемняет лишнее, в углу
  ячейки видно, сколько таких предметов всего, Alt + ЛКМ помечает избранные ячейки, а поиск по
  названию фильтрует инвентарь прямо во время игры.

## Что нового в 1.5.3 — визуалы мира, часть IV

* **Сглаживание картинки (№55).** Настоящий пост-процесс по кадру мира: края находятся по перепаду
  яркости и размываются строго вдоль найденного направления, поэтому лесенка на блоках и моделях
  исчезает, а ровные поверхности остаются резкими. Четыре режима качества, субпиксельная мягкость,
  опциональная резкость.
* **Новые килл-эффекты (№56).** Четыре собственных эффекта ByAzen: «Космос» схлопывает кольца в
  точку и разбрасывает звёзды, «Дракон» раскрывает огненные крылья, «Вода» расходится кругами и
  брызгами, «Гроза» бьёт молнией со вспышкой, плюс мягкая «Аврора» занавесами. Всё — геометрия и
  сглаженные частицы, никаких пиксельных текстур.
* **Кастомная камера (№59).** Плавное следование (взгляд мягко догоняет резкие движения мышью),
  отдача при ударе (кик, крен и сжатие зума) и кинематографический режим с «дыханием» зума и
  лёгким покачиванием кадра. Всё считается по времени кадра.
* **Предсказание траекторий (№63).** Модуль показывает, что случится дальше: куда растечётся вода и
  лава, что толкнёт поршень и куда уедет блок, как пойдёт редстоун (яркость линии — сила сигнала) и
  куда упадёт песок или гравий.

## Что нового в 1.5.2 — визуалы мира, часть III

* **Свои частицы (№51).** Мир наполняется мелкой жизнью: в снежных биомах кружатся снежинки, в лесу
  летят листья, у лавы поднимаются искры, на песке висит пыль, над водой всплывают пузыри. Стиль
  подбирается по блокам вокруг, у каждого своя физика — снег падает, искры взлетают, пыль висит.
* **Bloom (№53).** Лава, порталы, кристаллы, руды, факелы и огонь получают мягкое радиальное
  свечение с плавным «дыханием» и необязательными искрами. Свечение честно уходит за блоки и не
  светит сквозь стены.
* **Трейлы 2.0 (№58).** За элитрами вьётся спиральный завиток, за стрелами и трезубцами тянется
  шлейф, за снарядами и предметами — мягкая пыль. Частицы считаются по пройденному пути, поэтому
  след не рассыпается на медленных скоростях.
* **Подсветка блоков (№62).** Руды, контейнеры, рабочие станции, порталы и свои блоки (списком)
  обводятся градиентным контуром с переливом или пульсом, плюс мягкая заливка внутри.

## Что нового в 1.5.1 — визуалы мира, часть II

* **Glow ESP по категориям (№61).** Прежний режим подсветки был заглушкой — теперь он реально
  рисует мягкий ореол, лёгкую заливку и аккуратный контур вокруг цели. Категории: игроки, мобы,
  выпавшие предметы и контейнеры (сундуки, бочки, шалкеры), у каждой — свой цвет. Скан контейнеров

## Модули 1.2.0: Pulse Cosmetics и Kill Effect 3D

Оба мода встроены в клиент как вложенные jar-ы и управляются из списка модулей ByAzen (категория **Visuals**).

Косметика Pulse: крылья, плащи, головные уборы, одежда на теле, питомцы и граффити.

  (и их анимация закрытия) не рисуются, пока открыт ваш интерфейс, — раньше они всплывали

## Правила проекта

1. **Красивый рендер, никакой пикселизации.** Пиксельные/битмап-шрифты в проекте запрещены:
   только гладкие MSDF-шрифты (Montserrat, SF Pro) и сглаженная векторная графика. Всё, что добавляется в ByAzen, рисуется сглаженно:
   шейдеры/SDF, плавные скругления, градиенты, MSAA/суперсэмплинг, интерполяция координат и альфы
   (`float`, а не округлённые пиксели), мип-мапы и линейная фильтрация. Никакого pixel-art, `NEAREST`-фильтра,
   шага по целым пикселям и нарочито «пиксельных» текстур/иконок.
2. Все новые файлы, пакеты и ресурсы — в пространстве имён `byazen` (`rtx.byazen.*`, `assets/byazen/**`).
3. Никаких упоминаний старого имени в коде, ресурсах и UI.
