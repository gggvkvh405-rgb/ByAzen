# Чек-лист ByAzen — что сделано и как это проверить

Файл для ручной проверки: каждый пункт — идея из [IDEAS.md](../IDEAS.md) с конкретным действием в игре.
Отмечай `[x]` то, что проверил. Порядок — по версиям: сверху старое, снизу самое новое.

**Как поставить и что нажать в первую очередь**

1. Возьми в корне репозитория **`ByAzen-1.9.2.jar`** (последняя сборка; в игре её версию видно в хабе
   и в водяном знаке). Старые копии в папке `mods` лучше убрать — TLauncher складывает их как
   `ByAzen-1.0.0 (14).jar` и потом грузит не то, что нужно.
2. Нужны **Minecraft 1.21.11 + Fabric Loader 0.15+ (проверено на 0.19.5) + Java 21 и Fabric API**.
3. Открыть клиент: **Right Shift** — ClickGui. В нём: строка поиска, звёздочка — избранное,
   кнопка **«?»** в шапке настроек — инструкция по модулю, четыре кнопки-пресета настроек.
4. Команды в чате (префикс `.`): **`.help`** — список всех, **`.find <слово>`** — где найти настройку,
   **`.how <модуль>`** — как он работает, **`.hub`** — хаб (8 вкладок), **`.tutorial`** — тур,
   **`.diag`** — диагностика, **`.snapshot`**, **`.config`**, **`.home`**, **`.party`**, **`.irc`**.
5. Если что-то не так: **`.diag`** → вкладка «Почему лагает»/«Профиль», **`.help`**, кнопка
   «Скопировать лог» в модуле `Logs`.

Обозначения: **[ ]** — пункт не проверен, **[x]** — проверен и работает.

## 0. Основа клиента (1.0.0–1.2.1)

- [ ] **Переименование kimiko → ByAzen.** Нигде в интерфейсе, ресурсах и логах не должно быть «kimiko».
  Проверка: включи водяной знак и любой экран клиента, посмотри `logs/latest.log` — кроме исторических
  ссылок в README в самом jar строк нет (проверено: 0 вхождений в `ByAzen-1.9.2.jar`).
- [ ] **Красивый рендер, без пикселей.** Все панели, шрифты и иконки — сглаженные (MSDF Montserrat/SF Pro,
  векторные иконки). Проверка: открой ClickGui, хаб, плеер — «квадратных» пиксельных шрифтов быть не должно.
- [ ] **Клиент грузится без ошибок.** В логе ищи строки `[ByAzen]`, `[Render2D] Render2D initialized`,
  `[CommandManager] Initialized with 9 commands` — это наш клиент, ошибок после них быть не должно.
- [ ] **ClickGui (Right Shift).** Виджеты, категории, перетаскивание, поиск, пресеты настроек.
- [ ] **HUD-виджеты** — броня, поты, клавиши, таргет-хад, информация, ArrayList и т.д.
  Все таскаются в редакторе интерфейса.
- [ ] **Pulse Cosmetics и Kill Effect 3D (1.2.0/1.2.1).** Модули `Pulse Cosmetics` и `Kill Effect 3D`,
  кнопка «Открыть» в их настройках открывает окно (в 1.2.1 починен клик по строке-кнопке).
- [ ] **Музыкальный плеер (1.3.0).** Клавиша **M** — окно плеера; 25 станций SomaFM/Nightride FM,
  вкладки «Поиск» (каталог Audius) и «Свои ссылки», избранное, спектр и кнопки на HUD-виджете,
  громкость колесом мыши на виджете.

## Известные особенности (из твоего лога запуска)

- `Missing resource https://kimiko_tech/api/account/avatar/1` — это **старая сборка 1.0.0**:
  мёртвый адрес аватарки удалён ещё в 1.1.0. В 1.9.2 таких строк нет.
- `[byazen-freeze-profiler] ... render thread stuck ~470–976 ms` — это наш профайлер, он ловит
  паузу загрузки мира (генерация чанков, инициализация биомов). Один раз при входе — норма.
- `[ByAzen] Skipping mixin rtx.byazen.mixin.LevelRendererChunkFadeMixin because 'sodium' is installed` —
  так и задумано: с Sodium наш миксин тускнения чанков отключается, чтобы не конфликтовать.
- `Failed to parse into SignedJWT: null` / `Could not authorize you against Realms server` — это
  ванильная попытка авторизоваться в Realms (у TLauncher нет платной сессии), к клиенту отношения не имеет.
- В папке `mods` у тебя лежали `byazen-1.0.0.jar` и `ByAzen-1.0.0 (10).jar` — TLauncher их дублирует.
  Убери старые копии, оставь только `ByAzen-1.9.2.jar`, иначе легко проверить не ту версию.
